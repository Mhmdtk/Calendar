## Packages
date-fns | Date manipulation
date-fns-tz | Timezone support for dates
moment | Required for hijri-moment interaction
moment-hijri | Hijri date calculations
jspdf | PDF generation
jspdf-autotable | Table support for PDF generation
html2canvas | Capturing DOM elements for PDF
lucide-react | Icons
framer-motion | Animation library for smooth transitions

## Notes
- Tailwind Config must extend fontFamily to include Arabic fonts (Cairo, Tajawal)
- RTL support is critical, set dir="rtl" on the root element
- Integration with @shared/routes is required for API calls
